# Theorie

> Zurück zur [Übersicht](../README.md)

Dieser Ordner sammelt gemeinsame Theorie, kurze Erklärungen und externe Quellen, die für das Biketouren-Projekt tatsächlich relevant sind.

Mögliche Themen sind:

- Git und nachvollziehbare Commits
- Branching und Pull Requests
- CI/CD
- Container
- automatisierte und manuelle Tests
- Deployment
- Monitoring
- Sicherheit

Es soll nur Theorie abgelegt oder verlinkt werden, die das Team für konkrete Projektaufgaben benötigt. Quellen werden nachvollziehbar angegeben und Inhalte bei Bedarf mit der Projektdokumentation verknüpft.

Individuelle Lernjournale gehören ausdrücklich nicht in diesen Ordner und werden nicht in diesem Repository abgelegt. Externe Lernjournale werden ausschliesslich in der [Repository-Übersicht](../README.md) verlinkt.
