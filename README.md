## Arbeitsmodell

Das Team arbeitet cross-funktional. Entwicklung, Tests, Review, Dokumentation und Infrastruktur werden passend zur Aufgabe verteilt und regelmässig rotiert. Es gibt keine dauerhaften Spezialrollen; Wissen und Verantwortung sollen im gesamten Team geteilt werden.
